# 🍽️ CraveVerse — Food Discovery App

**Your craving. Your universe.**

CraveVerse is a React-based food discovery application designed to help users find meals according to their preferences, budget, and available time. It provides an interactive interface for exploring food options, applying filters, saving favourites, and managing a basket.

## ✨ Features

- **Smart Food Search:** Enter food preferences such as spicy chicken or healthy vegetarian meals.
- **Budget Filter:** Find meals that fit your budget.
- **Preparation-Time Filter:** Filter meals according to the time available.
- **Cuisine Filters:** Explore Indian, South Indian, Asian, Healthy, Italian, and Fast Food options.
- **Vegetarian Filter:** Find vegetarian meal options.
- **Food Cards:** View meal images, descriptions, restaurant names, prices, ratings, and estimated preparation times.
- **Favourites:** Save meals you like.
- **Basket Management:** Add meals and manage quantities.
- **Responsive Design:** A user interface designed to adapt to different screen sizes.

## 🛠️ Technologies Used

## 🚀 Getting Started

Follow these steps to run CraveVerse on your computer.

### Prerequisites

Install the following:

- [Node.js](https://nodejs.org/)
- npm, which is included with Node.js
- Git

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/Manju1181/craveverse-frontend.git
```

**2. Navigate to the project directory**

```bash
cd craveverse-frontend
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

Open the local URL displayed in your terminal to view the application.

## 📦 Production Build

To create a production build, run:

```bash
npm run build
```

To preview the production build locally, run:

```bash
npm run preview
```
